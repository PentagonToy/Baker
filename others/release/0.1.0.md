# Baker 0.1.0

Prepare Developer ID distribution with hardened runtime and secure timestamps for Baker and its bundled native tools. Existing captures, formula history, downloaded models and plugin settings retain their formats.

Apple notarisation and stapled-ticket validation are required before publishing this build. Changing from a local signing identity may require a one-time Screen Recording or Keychain approval. Later builds should retain the same Developer ID team and app identifier.
