# Baker 0.0.4

Capture and review with fewer interruptions. This update adds window capture, a compact formula popover and a short Quick Start. Recognition stays local.

## Changes

- Capture one application window with its own menu command and shortcut. Install through a DMG with large Baker and Applications icons.
- Review captured equations below the menu-bar icon. Open Workspace for editing, history and original-image comparison.
- Use consistent menu icons, aligned settings cards and calmer thumbnail movement between displays.
- Copy readable Unicode without unnecessary styling or constant warning markers. Unsupported conversions stay empty. Fraction rules remain clearer in reduced previews.
- Release idle formula-rendering resources and disable unnecessary OCR thread spinning. Manage the optional Offline Model for PDFs in Advanced.
- Try essential features through a permission-first Quick Start, or control capture, recording, history and conversion through the bundled JSON CLI.
- Retain a fixed signing identity across builds to reduce repeated privacy approval. Moving from an older signing identity can need one fresh Screen Recording approval.

## Install

Download **Baker-0.0.4-arm64.dmg**, open it and drag Baker to Applications. With Homebrew, use `brew install --cask pentagontoy/tap/baker` or `brew upgrade --cask baker`.

Requires Apple Silicon and **macOS 26.0 or later**. Optional PDF conversion requires **macOS 26.2 or later** and the unchanged PDF Engine 1.0.0. Existing captures, models and preferences stay outside the app bundle.

This build is **self-signed and not notarised**, without an Apple Developer ID certificate. macOS may block the first launch. Follow [first-launch and permission guidance](https://pentagontoy.github.io/Baker/help/troubleshooting.html) for a download you trust. Permission retention was checked on one development Mac, not every user’s system.

## Validation and files

Validation covers native packaging, signatures, Unicode, the CLI, permission and guide flows, formula rendering and accepted PDF examples on an M1 Pro. The release manifest records exact checks and source identity. A separate clean Mac, every supported macOS version and physical two-monitor animation timing remain untested. Compare recognised equations and PDF reading order with the original.

The release includes the DMG, `Baker-0.0.4-source.tar.gz`, `release-manifest.json` and `SHA256SUMS`. Baker source is AGPL-3.0-only. Dependencies retain their licences and accompanying source material.
