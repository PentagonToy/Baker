# Baker 0.0.5

Choose the formula model that suits your work. This update keeps formula weights outside the app and refines capture previews, formula controls and resource handling. Recognition runs locally after download.

## Changes

- Choose **Pix2Text**, **Texo** or **PP-FormulaNet plus-S** in Settings → Formula. Each downloads separately and keeps its own cache. Existing models and selections remain available.
- Download the selected model directly in Quick Start after granting Screen Recording permission.
- Let capture previews fill the display’s usable height, or choose a fixed limit from one to five.
- Use aligned controls across Settings, Workspace, History and the formula popover. Click outside the popover to dismiss it.
- Improve dark-capture recognition, Keynote bold and multiline output, and the Last Capture format selector.
- Reduce preview memory, cancel pending renders when clearing caches and inspect memory or active work through read-only CLI diagnostics.

## Install

Download **[Baker-0.0.5-arm64.dmg](https://github.com/PentagonToy/Baker/releases/download/v0.0.5/Baker-0.0.5-arm64.dmg)**, open it and drag Baker to Applications. With Homebrew, run `brew install --cask pentagontoy/tap/baker` or `brew upgrade --cask baker`.

Requires Apple Silicon and **macOS 26.0 or later**. Optional PDF conversion requires **macOS 26.2 or later** and the unchanged PDF Engine 1.0.0. Captures, downloaded models and preferences stay outside the app bundle.

This build is **self-signed and not notarised**. Follow the [first-launch guidance](https://pentagontoy.github.io/Baker/help/troubleshooting.html) for a download you trust. A persistent signing identity reduces repeated permission approval on the tested development Mac; other systems can still require approval.

## Files and validation

The release includes the DMG, corresponding source, `release-manifest.json` and `SHA256SUMS`. Baker source uses AGPL-3.0-only; dependencies and models retain their own notices, source material and licences. Formula assets remain in [Models 1.0.0](https://github.com/PentagonToy/Baker/releases/tag/formula-models-v1.0.0) and [Models 1.1.0](https://github.com/PentagonToy/Baker/releases/tag/formula-models-v1.1.0).

Validation covers the native app, signatures, formula workers, the CLI, model installation and documentation on an M1 Pro. The manifest identifies the tested source and packaged checks. A separate clean Mac and every supported macOS version remain untested. Review recognised equations and PDF structure against the original; no model guarantees error-free recognition.
