# Baker 0.1.3

- **Import from the web.** Paste a link in Clipboard & Files, add the page or PDF to the queue, and save it as PDF, Markdown or LaTeX. When a site requires sign-in, complete it before adding the source.
- **See progress per file.** PDF conversion shows the provider, pages completed and timing on the file’s row.
- **Capture across displays.** The area selection overlay now covers every connected display, including portrait monitors.
- **Find related actions together.** Use **Add Sources** for files, links and clipboard actions, **New** for formula inputs, and **Storage → Maintenance** to clear preview caches.

For Apple Silicon Macs running macOS 26.0 or later. The app and disk image are Developer ID signed and notarised by Apple.
