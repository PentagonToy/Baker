# Baker 0.0.2

**A keen eye. A fresh result.**

This update adds offline KaTeX and mhchem formula previews and separates the optional PDF engine from the capture app.

## Changes

- Preview standard operators, accents, limits, sized brackets, matrices and aligned equations with bundled KaTeX 0.19.0.
- Display mhchem chemical formulas, ions, isotopes and reactions. Chemical OCR accuracy is not established; chemfig structures remain unsupported.
- Normalise known OCR-spaced operators conservatively while preserving custom notation and copied source.
- Reuse one preview renderer with a bounded cache, Retina snapshots and isolated equation macros. Unsupported input retains its source; external images, links and HTML are blocked.
- Keep text and formula capture recognition included in the smaller app. Download and verify PDF Engine 1.0.0 when first using PDF conversion; manage it in Settings.

## Installation and offline use

Download `Baker-0.0.2-arm64.dmg`, drag Baker to Applications and open it. Apple Silicon and **macOS 26.0 or later** are required for the capture app. **PDF conversion requires macOS 26.2 or later** and a one-time engine download of about 1.06 GB. Download the engine before travelling; installed recognition and previews run locally without an OCR account. Existing captures and preferences remain outside the app bundle.

The app is ad-hoc signed and **not notarised**. macOS may block a downloaded copy. Validation ran on an M1 Pro with 16 GB RAM; a separate clean Mac and every supported macOS version have not been tested.

## Validation and files

Formula preview regression passed 176 checks, including supplied-style equations, chemistry, Retina scale, cancellation, cache and source fallback. Research-PDF Markdown and complex-table cells/captions matched accepted results. The PDF models and conversion logic are unchanged in this update.

- `Baker-0.0.2-arm64.dmg`: capture app with included text/formula recognition and optional PDF setup.
- `Baker-0.0.2-source.tar.gz`: corresponding source, build scripts and accompanying dependency source material.
- `SHA256SUMS` and `release-manifest.json`: hashes, tested source commit and validation scope.

Baker source is AGPL-3.0-only; dependencies retain their own terms. Preview support does not guarantee OCR correctness or destination-app compatibility. Review equations, names and PDF reading order against the original.
