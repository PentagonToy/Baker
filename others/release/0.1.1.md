# Baker 0.1.1

Collect pages from a reader window and save one PDF, with optional on-device searchable text.

- Choose a window visually, then capture the whole window or an area within it.
- Turn pages using the right-arrow key or a chosen button, without moving the pointer. Automatic scanning stops when the page no longer changes.
- Pause, review, reorder or retake pages. Closing keeps the draft for later.
- Inspect and control a prepared Scan session through the CLI.
- Use simpler website navigation and refined Scan controls and thumbnails.

Baker is Developer ID signed and notarised by Apple. Existing captures, models and settings are preserved. Automatic page turns require control access; background support depends on the reader. See the [Scan guide](../../docs/help/scan.md).
