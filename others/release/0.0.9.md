# Baker 0.0.9

Add one optional OCR plugin from a ZIP in Advanced. Choose Baker or Plugin first independently for formula OCR, PDF → Markdown and PDF → LaTeX. Approved code handles its supported jobs through a documented JSON protocol; optional API keys stay in macOS Keychain. Plugins can provide a compact in-app setup window; the SDK includes a reusable login helper. No external OCR connector is bundled. History controls share one size, and formula results can be retained for 7, 10, 30 or 90 days, or without an age limit.

Built-in recognition remains local. Failed plugin jobs try an installed local model once; cancellation does not retry. Usage distinguishes plugin completions from Baker · Local with smaller amber provider badges and supports confirmed reset. Results and progress identify the provider that actually completed the job. Execution details are available separately in the approval prompt. Removing a plugin deletes Baker’s saved key; its process receives a limited environment.

Update notices display formatted release notes with headings, lists, emphasis and links.

Plugins run with user permissions, rather than in a sandbox. Install trusted code and review its data handling, costs and service terms. See [plugin setup and development](../../docs/help/plugins.md).

The Apple Silicon build is locally signed and not notarised. Verification uses synthetic plugins without external accounts; provider-specific compatibility depends on the separately installed adapter. Model archives retain their existing licences, source and checksums.
