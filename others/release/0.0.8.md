# Baker 0.0.8

Add one optional OCR plugin from a ZIP in Advanced. Approved code can handle formulas and PDFs through a documented JSON protocol; optional API keys stay in macOS Keychain. No external OCR connector is bundled.

Built-in recognition remains local. Failed plugin jobs try an installed local model once; cancellation does not retry. Usage distinguishes plugin completions from Baker · Local and supports confirmed reset. Results identify the provider that completed the job.

Plugins run with user permissions, rather than in a sandbox. Install trusted code and review its data handling, costs and service terms. See [plugin setup and development](../../docs/help/plugins.md).

The Apple Silicon build is locally signed and not notarised. Verification uses synthetic plugins without external accounts; provider-specific compatibility depends on the separately installed adapter. Model archives retain their existing licences, source and checksums.
