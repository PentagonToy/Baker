# Baker 0.0.1

**A keen eye. A fresh result.**

Baker is a local capture and recognition app for Apple Silicon Macs. Capture a detail, recognise an equation or convert a PDF without an OCR account.

## Included

- All, Area and Scrolling capture, plus text and formula recognition.
- Editable capture thumbnails with opaque filled shapes for masking.
- Formula Workspace with image drops, saved history and LaTeX, Markdown, Keynote and Unicode output. New input keeps the preview and copy fields empty.
- Structured PDF conversion with equations, tables, figures and page-based progress estimates.
- Silent video/GIF recording, configurable global shortcuts, three appearance choices and one save folder.

## Recognition

Formula images use Pix2Text MFR 1.5 through ONNX Runtime. PDFs combine native characters, DocLayout-YOLO and a mixed-precision GLM-OCR model with a small Baker adapter through MLX. Screenshot text uses Apple Vision or local Tesseract. Recognition runs on the Mac.

See [models and references](https://pentagontoy.github.io/Baker/help/recognition.html) for checkpoint lineage, adaptations, upstream repositories and measured limits. The small adapter has not established a general accuracy improvement over its base model.

## Requirements and installation

Apple Silicon and **macOS 26.2 or later** are required. The interface is English. No Python paths, Homebrew installation or model configuration is needed for a complete packaged build.

Open the supplied disk image, drag Baker to Applications and launch it. Baker appears in the menu bar. Allow Screen Recording for screen capture; imported files do not require this permission. The initial save folder is `~/Documents/Baker`.

## Download files

- `Baker-0.0.1-arm64.dmg`: the complete app and local recognition engines.
- `Baker-0.0.1-source.tar.gz`: Baker source, build scripts and accompanying dependency source material.
- `SHA256SUMS`: checksums for the release files.
- `release-manifest.json`: source commit, versions, hashes and validation scope.

The app is ad-hoc signed and **not notarised**. macOS may block a downloaded copy; this release does not claim Developer ID validation. The development checks ran on an M1 Pro. A separate clean Mac and every supported macOS version have not been tested.

## Known limits

Review OCR symbols, names, table spans and reading order against the source. Complex PDF tables can be slow; multilingual scans need further validation. Scrolling is manual and downward only. Recordings have no audio. Formula confidence is a model score, not verified correctness.
