# Baker 0.1.5

- **Install with a double-click.** Open Baker in the disk image and choose Install. Baker replaces the app in Applications and opens there, preserving captures, settings and plugins. The previous app stays available if installation fails and moves to the Trash after a successful launch.
- **Keep filenames short.** New captures use `img_`, `fx_`, `vid_` or `gif_` followed by `yyyyMMdd_HHmmss`. Captures saved in the same second receive a numbered suffix. Existing files stay readable.

Quit Baker before installing an update. For Apple Silicon Macs running macOS 26.0 or later; PDF conversion requires macOS 26.2 or later. The app and disk image are Developer ID signed and notarised by Apple.
