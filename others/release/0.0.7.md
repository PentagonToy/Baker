# Baker 0.0.7

This edition keeps recognition on your Mac. It includes three optional formula models, the optional PDF engine, capture and recording, image editing, searchable formula history and the agent CLI.

OCR account sign-in and cloud conversion are absent. Existing capture files and saved formula text remain readable. Local usage counts retain their tracking date; counters for retired services are ignored. Model downloads and optional update checks still contact GitHub.

The Apple Silicon build is signed locally and is not notarised. See [opening a downloaded app](../../docs/help/troubleshooting.md#opening-a-downloaded-app).

Model archives retain their original licences, provenance, corresponding source and SHA-256 identities. See [model packages](../../docs/models/README.md).
