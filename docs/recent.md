# Recent

The **Recent** menu category returns to captures, recognition results and exports.

| Menu item | Action |
| --- | --- |
| Last Capture… | Reopens the latest captured image |
| Capture History… | Browses saved captures and restores their previews |
| Open Capture Folder | Opens `~/Pictures/Baker` in Finder |
| Formula Workspace… | Opens the current session’s formula results and copy formats |
| Last Result… | Opens the recognition editor |
| Last Export… | Opens the current PDF, video or GIF export, when available |

## Capture history

The stack shows three recent captures by default; choose one to five in Settings. Older cards leave the stack when it fills. Closing a preview keeps its saved file. **Capture History…** restores previews and copies earlier captures, including after restarting Baker. **Open Capture Folder** opens the originals in Finder. Imported and clipboard images are also copied into this archive without changing their source.

History does not automatically delete images. At 10,000 records Baker refuses another import and reports the problem.

## Edit or copy a result

Use **Last Result…** to correct recognised text or LaTeX. Unicode output is also editable. Copy sends the current result to the clipboard. Opening the result editor automatically is optional in [Settings](settings.md).

## Saved files and session results

Capture images persist after quitting. Formula recognition results and edits remain in memory for this session, up to eight formulas; copy them into a document before quitting. Unsaved PDF, video and GIF exports are temporary and are replaced by the next export or removed on normal quit. Save an export before starting another.
