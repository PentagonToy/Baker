# Clipboard & Files

Choose **Open Files…** or **Convert PDF** to open the file workspace. It stays visible when you switch to Finder or another app; **Choose Files…** opens a file-selection sheet attached to this window. Drop images and PDFs into it, or choose **Choose Files…** and select several files.

1. Add up to 50 files.
2. Choose Markdown or LaTeX for PDFs.
3. Choose **Process Files**. Baker handles one file at a time.

Images are copied into capture history. Choose **Formula** beside an imported image to recognise it. PDF results have a **Save…** button; save them before clearing the list or quitting. Original files stay in place.

The workspace also offers **Clipboard Image** and **Read Clipboard Text**. The same actions remain available in the menu. Baker reads the clipboard when requested.

PDF conversion currently extracts text; it does not rebuild equations, tables or columns. See [PDF limits](../help/limits.md#pdf-conversion).
