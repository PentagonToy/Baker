# Recent

Return to saved captures and results from the **Recent** menu.

| Item | Opens |
| --- | --- |
| Open Capture Folder | The chosen save folder in Finder |
| Last Capture | The latest image |
| Capture History | Saved images, formulas, videos and GIFs |
| Last Result | The recognition editor when a result is available |
| Last Export | The current recording or single-file export |

Capture History shows thumbnail cards in date order. Filter by **All**, **Images**, **Formulas**, **Videos** or **GIFs**. Search by filename, LaTeX or Unicode. **Open Formula** reopens a saved equation without OCR; **Show Preview** opens an image. SVG cards open a vector preview with copy, save and drag actions; they do not enter the raster editor. SVG files appear under Images. **Play Video** and **Open GIF** use the Mac’s default application. Copying a recording copies its file. The context menu can reveal the original in Finder.

For formula text rather than capture images, use the [Formula Workspace grid](../help/formula.md#history). It supports direct format-specific copy and confirmed removal of individual or Command-selected formula records while keeping the original images.

Closing a capture thumbnail keeps its image and saved result. Recordings are saved automatically in the chosen folder and remain in history after Baker quits. Existing temporary recordings from older versions are not imported automatically. Files processed in the file workspace remain temporary until saved, cleared or Baker quits.

Choose the capture folder in [Settings → Storage](../help/storage.md). You can change the Recent menu order in Settings → Menu.

Use Settings → Storage → Caches → Clear Image Cache to discard thumbnail cache and reconcile files deleted in Finder. Retention defaults to no image limit; reviewed limits move images to Trash. Videos and GIFs are unaffected.
