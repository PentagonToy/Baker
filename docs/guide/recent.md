# Recent

Return to saved captures and results from the **Recent** menu.

| Item | Opens |
| --- | --- |
| Last Capture | The latest image |
| Capture History | Saved images and searchable formula results |
| Open Capture Folder | The chosen save folder in Finder |
| Last Result | The recognition editor |
| Last Export | The current video, GIF or single-file export |

Search Capture History by filename, LaTeX or Unicode. Choose **Formula** to reopen a saved equation without OCR. Closing a thumbnail keeps its image and saved result.

Save temporary exports before quitting. Files processed in the file workspace remain in that workspace until cleared or Baker quits.

Choose the capture folder in [Settings → General](../help/storage.md).
